# Word lists for the writing check

`vocab-levels.json` is built from:

- **CEFR-J Wordlist, version 1.5** (A1–B2) — © Tono Laboratory, Tokyo University of Foreign Studies.
  Free for research and commercial use, provided the dataset is cited.
  Source: https://github.com/openlanguageprofiles/olp-en-cefrj
- **Octanove Vocabulary Profile C1/C2, version 1.0** — Octanove Labs, licensed under CC BY-SA 4.0.
  Source: https://github.com/openlanguageprofiles/olp-en-cefrj
- **google-10000-english** (no-swears list) — https://github.com/first20hours/google-10000-english,
  used only as a frequency fallback for words that are not in the CEFR lists.

Grammar and spelling suggestions come from the LanguageTool public API (https://languagetool.org).
